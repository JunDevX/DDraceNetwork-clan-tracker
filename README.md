# DDraceNetwork Clan Tracker — C# Edition

This project is a fully rewritten and modernized version of the original Python-based DDraceNetwork clan tracker.  
The application has been completely ported to **C#**, featuring a redesigned interface, improved performance, and an expanded feature set.

The original concept and intellectual property belong to the developer  
**https://github.com/0x03C9**, who created the initial Python implementation.  
This C# edition preserves the core idea while delivering a more robust and user‑friendly experience.

---

## Key Improvements in the C# Version

### ✔ Full Rewrite in C#
The entire codebase has been rebuilt using C#, providing better structure, maintainability, and performance compared to the original Python script.

### ✔ Modernized UI & UX
The design has been refreshed to offer a cleaner, more intuitive interface, making clan tracking easier and more accessible.

### ✔ Enhanced Functionality
While keeping the original features, the C# version introduces:
- Faster data processing  
- More reliable member tracking  
- Improved logging system  
- Better file handling and configuration options  

### ✔ Compatibility & Stability
The application is optimized for Windows environments and offers significantly improved stability during long‑term tracking sessions.

---

## Original Features (Preserved & Improved)

The following features from the original Python version have been retained and enhanced:

- **Structured Formatting:**  
  Clean and readable output files containing all tracked clan data.  
  

- **Smart Member Tracking:**  
  Automatic detection of clan changes and prevention of duplicate entries.  
  

- **Daily Auto‑Logging:**  
  Optional automated daily logs with customizable save directories.  
  

- **Flexible File Naming:**  
  Customizable names for database and temporary log files.
