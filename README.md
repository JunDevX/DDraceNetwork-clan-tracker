# DDraceNetwork-clan-tracker
A simple and lightweight Python script designed to track and gather information about clan members in DDraceNetwork (DDNet).
Features:
1. Structured Formatting: Compiles all tracked data into a single, clean .txt file using a readable format:
[Clan Name]
* Member 1
* Member 2
2. Smart Member Tracking: Automatically detects when a player changes their clan and removes them from their previous one, preventing duplicates.
3. Daily Auto-Logging: Features an automated daily logging system. This can be easily disabled, and you can fully customize the target directory for saving log files.
4. Flexible File Naming: Allows you to set custom names for both the main player database file and the temporary log file before it is archived into the daily logs directory.
